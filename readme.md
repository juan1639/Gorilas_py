# Gorilas py
## Recreación en python del juego clásico Gorillas de Microsoft (qbasic) de 1991

---

- Juego de 2 jugadores en el que cada gorila deberá lanzar una banana explosiva intentando alcanzar al otro.
- Se deberán introducir los grados y la velocidad para efectuar el lanzamiento.
- El ganador será el que llegue a 3 victorias.
